# Saulo Faria

My personal website—a little about me, the work I have done, and the products I have built.

Built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To create a production build:

```bash
npm run build
npm start
```

## Make it yours

Feel free to copy, adapt, or reuse the code and layout for your own website. Just replace my personal content, résumé, and images with yours.
